Change
The reply result uses the chat id returned with the stored message, including
when an older session handle no longer has a local reverse mapping. An unknown
chat refreshes the inbox before classification. Stored main chat replies say
delivered to the main chat; confirmed peer replies name their side thread.
Missing or null stored message ids report delivery unconfirmed.

Routing, peer refusal, closed conversation and reopen decisions remain with
the existing code and backend. Known side threads still require peer handoff
confirmation. If discovery still gives no chat kind, the existing conservative
handoff check remains, but its result names only the chat, not an invented side
conversation. The Sent (message_id: N) prefix remains for session binding.
