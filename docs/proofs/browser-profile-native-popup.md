# Managed popup observer qualification

The managed agent browser now routes target observation over the original browser's private flattened CDP session. It does not open a CDP port or add another relay. Owner control still travels through HOAI.

The old second legacy attachment could stall a popup's first POST while waiting for observer initialization. A private controller-release experiment sometimes completed the page but missed its native `loadingFinished`. That experiment was discarded. The final adapter claims the original native attachment once and uses a pinned in-process Playwright child session on the same owned pipe. It queues Network, Debugger and nested target observation before the first resume, then requires all native answers before marking observation ready.

The adapter requires the canonical installed Playwright connection and the exact pinned implementation. It checks original client, server, browser, root, parent, dispatcher, wire and callback identities. It refuses foreign session collisions, copied receipts, unobserved or stale attachments, unknown cleanup and replaced private objects. Session/history and global/per-session command bounds apply before dispatch. A deadline does not release physical work. Native callback settlement releases the reservation, including after disposal or disconnect. Browser shutdown remains independent of that settlement.

The five touched suites passed 103 tests with zero failures or skips. `tsc --noEmit` exited 0. Twenty copied executable mutations each printed the changed line, failed a selected test, restored the exact source bytes and passed. They cover identity, receipt ownership, collisions, parent/callback ownership, cleanup, physical accounting, bounds, observer answers, frozen births and refusal of legacy fallback. The JSON records each exact line and hash.

Three consecutive final LF-source native runs used nonroot sandboxed Chromium 153.0.8010.12 on the immutable ec984 image with the three explicit source overlays. Each proved ordinary ordered three-tab schema2 capture/restore and exact selected-page MCP initialization; the original popup POST exactly once, its 303 redirect, final GET/200 and native completion; and the original opener relationship. The command timeline records observer dispatch before `Runtime.runIfWaitingForDebugger` and every positive native answer. It does not pretend those answers arrived before dispatching resume.

Live popup relationships still refuse schema2 movement before source admission closes, preserving both pages. After the popup closed with completed native network history, an encrypted data-only checkpoint succeeded. An executable native mutation withheld only the popup's resume packet and failed on its page-event deadline after the ordinary-tab checks. Restoring the exact final source passed again. Every final positive and negative run confirmed all three browser PIDs gone, the fixture server closed and the named disposable container absent, without a forced stop.

This native probe uses a synthetic coordinator, CAS, URL-review capability and portable extras. It qualifies the final observer/runtime/probe bytes against the ec984 dependency image. It is separate from actual two-machine HOAI, newer KDF, permission, file-transfer and backup proofs. It does not exercise a real user's login or prove physical human approval. Popup navigation remains usable in the original browser; opener relationships and unfinished sign-ins are not converted into safe GET replay permissions.

Earlier legacy-controller failures and the eight positive private flat-session prototype runs are retained as diagnostics. Their old wrapper's `productQualification:true` and `baseCommit:3d660` metadata were inaccurate for the prototype; its actual base was ec984 plus a private overlay. They are excluded from final product-source qualification. The JSON lists the three final LF receipts, source hashes, mutations and exact cleanup evidence.
