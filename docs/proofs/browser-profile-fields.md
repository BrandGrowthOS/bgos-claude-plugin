# Managed plaintext field proof

The frozen field helper supports exact ordinary native text inputs and textareas after one fresh recipient approval. It retains original snapshot handles, page/document/full runtime authority and original signed arguments. Credential and unknown-purpose fields refuse. No engine or bridge file changed.

Four touched plugin suites pass 62 cases with zero skips. The touched native permission suites and backend permission suites pass 29 and 20 cases, respectively. Plugin, backend and frontend typechecks are clean. Exact source hashes and the recorded commands are paired with the JSON receipt.

A disposable Linux uid1000 container with network disabled and sandboxed Chromium 153.0.8010.12 ran the actual new helper through pinned MCP snapshot refs and clean utility handles. Fourteen cases passed: ordinary input/textarea, generated labels/aria purposes, owning-form credential metadata, sibling credential labels, password/OTP, unknown purpose, replaced element, type/autocomplete race, hostile main-world prototype, focus redirection, same-URL navigation, revocation, a real subframe and post-write event changes. The native browser PID was gone and the container was normally absent; no forced stop was used. Authority and human approval were synthetic.

The native mutation removed classification equality from executable helper line 84. The real replacement-node case failed with AssertionError and exit 1. Loading the exact original helper again passed all 14 cases and positive cleanup. The mutation image and original image identities, helper hashes and safe raw receipt hashes are in the JSON. No field text is emitted by the native receipt.

Twenty-five additional isolated executable-load mutations each printed the actual changed line, failed a focused test with an assertion, kept workspace source bytes unchanged and passed the restored test. They cover supported modes, batch uniqueness, original args/signal/authority/page/native frame/connection/world, capture and independent cleanup, physical reservation, one use, all-fields validation, partial native outcomes, Companion executor/uncertainty/shutdown, runner/client method kind, main native label and backend stored-RPC kind/label.
