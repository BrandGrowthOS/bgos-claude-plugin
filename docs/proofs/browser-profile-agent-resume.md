# Agent ordinary-tab checkpoint qualification

The managed runtime supports explicitly negotiated schema2 checkpoints. Schema1
retirement and automatic backup remain unchanged. Schema2 stores encrypted ordered
GET navigation hints and the actual selected page. It does not transfer live DOM,
browser history, POST submissions, authentication pages or popup relationships.

The target ledger requires an observed successful completed document GET with the
exact current native target, top-level frame and loader. A redirect cannot turn an
original POST into a GET permission. Capture reads native CDP title/frame metadata
after script freeze and before destruction, and rejects a changed snapshot. Only a
fresh ordinary opaque native blank is allowed. Current and birth opener metadata,
inherited blank contexts and ambiguous visited blanks refuse before source close.

Incoming query or fragment URLs require a constructor-only private capability.
The Companion validates version2 source metadata as the acting human's desktop,
matches its exact locally reviewed public pin and re-reads the request's current
source grant immediately before inactive stage. The capability binds the request,
checkpoint hash, crypto context, source pin and physical runtime. A serialized flag
or tool argument cannot issue it. Tabs stay private and inert until fresh HOAI
activation authority. Each exact URL opens once. Failed or unknown navigation stops
the destination without an automatic retry. Selecting the restored page through
the existing engine does not add a duplicate blank tab.
